# 결 — 한국판 사주 리포트 베타

Next.js App Router + TypeScript + **일반 CSS**. 모바일 화면 폭(최대 480px)으로 제작했고 PC에서는 가운데에 같은 화면이 표시됩니다. Tailwind, Sass, CSS-in-JS를 사용하지 않습니다.

## 시작하기

Node.js 22 이상과 npm을 권장합니다. 개발 당시 Node.js 24에서 검증했습니다.

```sh
npm ci
npm run dev
```

http://127.0.0.1:4173 에서 확인합니다. 외부 계정이나 API 키 없이 동작합니다. 개발 서버의 기본 주소는 위 주소로 고정되어 있습니다. 다른 주소나 운영 환경에서는 `.env.example`을 참고해 `APP_ORIGIN`을 정확한 사이트 주소로 설정하세요.

```sh
npm run test       # 달력, 입력 검증, 해설 분기, 임시 데이터 접근 테스트
npm run format     # 일반 CSS와 코드 정리
npm run typecheck
npm run test:e2e   # 설치된 Google Chrome 사용, 없으면 Playwright 설정의 channel 조정
npm run build
npm start          # production 모드에서는 모의 결제 차단
```

CSS는 의미 있는 일반 클래스명을 씁니다. 기본 화면은 모바일 전용이며 `--page-width`를 바꾸면 PC 미리보기의 폭도 변경됩니다. 서체나 이미지 CDN 요청은 없습니다. 미확정 캐릭터 시안은 저장소 루트의 `design/characters/`에 있고 개발 모드에서만 `/character-concepts` 경로로 확인할 수 있습니다. 이전 정적 샘플은 `archive/static-prototype/`에 보관합니다.

## 동작하는 범위

- 별명, 성별(여성·남성·다른 성별·밝히지 않음), 양력/한국 음력, 윤달, 출생시간 또는 시간 모름, 사주×MBTI 상품의 필수 유형 선택
- 한국 음력→양력 변환, 절기 기준 년주·월주, 일주·시주 계산
- 확인된 원국의 표면 오행 개수, 십성·지장간·월지 계절·육합/충에서 선택한 근거를 사용하는 관계 해설 초안
- 선택한 관심 장면을 도입 질문·상세 상황·이번 주 실천에 반영, 각 장의 근거 펼쳐보기
- 무료 요약→목차/예정 가격→모의 주문 동의→전체 리포트 체험
- 입력 수정, 오류 복구, 데이터 지우기, 접근 소유권·만료 처리

**MBTI 검사는 제공하지 않습니다.** 사용자가 선택한 유형만 참고하며 미입력 시 추측하지 않습니다. 공식 검사 문항, 공식 리포트, 인증 로고를 사용하지 않습니다. 상표 표시·상품명은 출시 전 별도 검토 대상입니다.

## 계산 정책과 한계

- 현재 범위는 **양력 1990-01-01 이후, 한국 출생, 고정 KST(UTC+9)** 입니다. 과거 한국의 표준시·서머타임 이력을 잘못 적용하지 않도록 1990년 전 입력은 명시적으로 거절합니다.
- 음력 변환: MIT `korean-lunar-calendar`. 중국 음력과 한국 음력을 같은 달력으로 취급하지 않습니다. 음력 2월 30일은 존재할 수 있어 음력 입력에는 HTML 양력 날짜 선택기를 사용하지 않습니다.
- 절기: MIT `lunar-typescript`의 절입 순간을 사용합니다. 라이브러리의 UTC+8 절기 시각과 KST 입력의 한 시간 차이를 년주/월주 계산에 반영합니다.
- 일주: 한국 달력의 간지 일진. **자정(00:00)에 일주 변경**, 시주는 이 일간 기준으로 계산합니다. 야자시·조자시를 별도 학파 기준으로 바꾸는 옵션은 아직 없습니다.
- 출생지별 진태양시·경도 보정, 해외 시간대, 대운, 용신/신강 판단은 구현하지 않았습니다.
- 출생시간 미상은 시주를 생략합니다. 절기 변경일이면 하루 시작/끝의 년주·월주를 비교해 변하는 주는 미확정으로 반환합니다. 정오를 실제 출생시간처럼 보여주지 않습니다.
- 원국 표의 오행은 확인된 천간·지지의 단순 개수입니다. 별도로 십성·지장간·월지 계절을 계산하지만 오행 개수에 가중치로 합산하지 않습니다. 계절 전환 월지의 표시 기준, 육합/충 선택, 규칙·검수 상태는 [`관계 해석 엔진`](../docs/INTERPRETATION_ENGINE.md)에 기록합니다.
- 성별은 사용자 프로필 입력값으로 표시합니다. 현재 제공하는 사주 네 기둥과 해설에는 반영하지 않으며, 성별에 따라 달라지는 대운 계산은 아직 구현하지 않았습니다.
- 알려진 음력 변환 사례와 간지 기준일, 라이브러리 절기 경계 회귀 테스트가 있습니다. 국내 전문 만세력과 대규모 교차 검증을 완료한 상용 엔진은 아닙니다.

## 결제·리포트·데이터

현재 상세 해설은 **검수용 규칙 기반 초안**입니다. LLM 호출, PG 결제, 실제 청구, 이메일, DB, 로그인, 광고 추적은 연결하지 않았습니다. 출생정보를 외부 AI에 전송하지 않습니다.

해설은 상품별 `traditional-0.1.0` / `relationship-0.3.0` / `mbti-0.1.0`, 계산 특징은 `saju-facts-v1`로 버전을 기록합니다. 각 장은 `chart / mbti / focus` 근거를 구분하며 내부 `audit`에 실제 적용 조건을 남깁니다. 이 기록은 서버 임시 리포트에만 보관하고 무료 API에 전체 상세 규칙이나 유료 문안을 반환하지 않습니다. 규칙 버전이 바뀐 임시 결과는 재생성이 필요합니다. 자동 테스트는 구현의 일관성 검사이며 명리 전문가의 문안 검수나 외부 만세력 교차 검증을 대신하지 않습니다.

`POST /api/reports`는 무료 부분만 반환합니다. 상세 챕터는 서버에 두고 클라이언트 번들에 포함하지 않습니다. `POST /api/reports/:id/demo-checkout`은 개발 모드에서만 동작하고, production에서는 항상 403입니다. 화면에 예정 가격 12,900원과 실제 체험 청구액 0원을 구분해서 표시합니다. PG 테스트 결제가 아닌 자체 모의 주문입니다.

리포트는 프로세스 메모리에 최대 1시간 보관하고 만료 타이머로 삭제합니다. 서버 재시작 시 유실됩니다. 브라우저당 하나의 리포트를 유지하고, 쿠키의 임의 세션 ID로 소유권을 확인합니다. 입력 수정 후 재생성/전체 초기화 시 이전 리포트를 삭제합니다. 브라우저 localStorage/sessionStorage에는 출생정보를 저장하지 않습니다. 공개 배포나 실제 판매에 적합한 영속 저장소·인증은 아직 아닙니다.

API 요청은 4KB 제한, 서버 입력 검증, 동출처 검사, no-store 응답을 적용했습니다. 운영 전에는 속도 제한, 악용 방지, 운영 관측, 인증, 실제 주문 권한 검증도 필요합니다.

## 메인과 세 가지 상품

`/`는 상품 선택 메인입니다. `/readings/traditional`, `/readings/love`, `/readings/mbti`에서 각 콘텐츠를 시작합니다. `features/reading/catalog.ts`는 상품 표시와 목차, `features/reading/server/create-report.ts`는 상품별 생성 분기입니다. 공용 리더·임시 저장은 `features/reading`, 개별 해석은 `traditional/relationship/mbti`에 분리했습니다. 입력 `theme` 기본값은 `traditional`입니다. MBTI 상품은 유형 필수이며 다른 상품은 유형을 서버에서 제거합니다. [콘텐츠 구조](../docs/CONTENT_ARCHITECTURE.md)를 참고하세요.
