# 웹툰형 리포트 경험 스토리보드

상태: 검증할 경험 가설 · 2026-09-25

## 목표 감각

사용자가 `내 이야기를 설명하는 만화 속에 내가 들어왔다`고 느끼게 한다. 주인공은 안내 캐릭터가 아니라 사용자다. 캐릭터는 장면을 열고 질문하며 해석을 전달한다. 사용자의 사진이나 얼굴을 받아 아바타로 만들 필요는 없다. 닉네임, 출생정보에서 계산한 사주, 선택한 MBTI가 **어떤 장면과 해설을 보여줄지**에 영향을 주어야 한다.

읽기 흐름은 `궁금한 질문 → 나와 닮은 장면 → 해석 근거 → 다음 장면에 대한 질문 → 유료 상세`다. 스크롤하는 동안 감정적 장면과 짧은 해설이 번갈아 나온다. 점술적 해석과 계산된 원국을 구분하고, 특정 연애 결과를 단정하지 않는다.

## 관계 리포트의 첫 장면 예시

| 장면 | 사용자에게 보이는 것 | 목적 |
| --- | --- | --- |
| 1. 입장 | 선택한 안내 캐릭터가 `{닉네임}`에게 한 가지 관계 고민을 묻는다. | 자신의 이야기라는 기대를 만든다. |
| 2. 장면 | 관계에서 먼저 다가가거나 기다리는 상황을 짧은 그림과 대사로 보여준다. | 일상에서 떠올릴 수 있는 장면에 들어가게 한다. |
| 3. 해석 | 해당 사주 요소와 입력한 MBTI가 장면을 어떻게 다르게 읽게 하는지 한두 문단으로 설명한다. MBTI가 없다면 그 비교를 생략한다. | 개인화의 근거와 한계를 드러낸다. |
| 4. 질문 | `나는 어느 순간에 마음을 열까?`처럼 사용자가 스스로 답할 수 있는 질문을 남긴다. | 다음 장면으로 넘어갈 이유를 만든다. |
| 5. 상세 안내 | 유료 장에서 다룰 구체적 주제·분량·가격을 보여준다. | 기대할 내용을 분명히 한 뒤 선택하게 한다. |

이 표는 카피와 장면의 **구조**다. 실제 문안은 사주 계산 정책과 콘텐츠 검수를 거쳐 따로 작성한다. 장면 2는 사용자에게 없는 성향을 사실처럼 단정하지 않도록 선택지나 조건부 표현으로 설계한다.

## 시제품 범위

- 관계 리포트 무료 부분의 **한 장면**을 세로형 패널 4~6개로 재구성한다. 먼저 정적인 그림·대사·해설로 읽기 흐름을 확인한다.
- 첫 안내자는 A안에서 출발한 여울로 선정했다. 현재 도입 장면과 관심 장면 선택, 무료 결과 도입, 상세 장 넘기기를 구현했다. 시범 독자의 이해도와 몰입감 검증은 남아 있다.
- 시제품과 첫 출시에서는 캐릭터 표정·배경·상황 그림을 미리 제작한다. 사용자별 결과에는 입력에 따라 장면을 선택하고 HTML 대사·닉네임·해설을 조합한다. **사용자마다 새 이미지를 생성하지 않는다.**
- 컷의 역할을 `상황`, `캐릭터의 반응`, `사주 근거`, `사용자 질문`으로 나눈다. 같은 정보를 그림과 글로 반복하지 않는다.
- 무료 부분에도 완결된 깨달음 하나를 준다. 유료 부분은 별도 장면과 더 깊은 해설로 이어간다.
- 영상은 광고나 시작 장면에서만 먼저 시험한다. 결과 본문은 느린 연결에서도 읽을 수 있게 정적 이미지와 텍스트를 기본으로 한다.

이 구성은 방문자 수에 비례한 이미지 생성 API 비용과 대기 시간을 피하면서도, 원국·선택 MBTI에 따라 다른 장면과 문장을 보여줄 수 있다. 유료 구매자에게만 개인화 표지나 특별한 한 컷을 생성하는 방안은 실제 수요와 단가를 확인한 뒤 별도로 판단한다. [OpenAI Docs 이미지 생성 비용 안내](https://developers.openai.com/api/docs/guides/image-generation)의 예시 가격은 변경될 수 있으므로 운영 견적에 고정값으로 사용하지 않는다.

## 화면·품질 원칙

- 세로 스크롤에 맞춘 짧은 패널을 쓴다. 작은 화면에서 대사·본문을 확대 없이 읽을 수 있어야 한다.
- 말풍선 속 텍스트도 실제 HTML 텍스트로 제공하고, 장식 이미지는 대체 텍스트·접근성 기준을 따른다.
- 움직임은 장면 전환을 돕는 정도로 제한하고 `prefers-reduced-motion`을 지원한다.
- 각 장면의 개인화 입력과 해설 근거를 제작 문서에서 추적할 수 있게 한다. AI 문안은 생성 후 검수 기준을 통과해야 한다.
- 캐릭터, 의상, 색채, 대사, 컷 연출은 독자적으로 만든다. 특정 경쟁 서비스의 캐릭터나 장면을 재현하지 않는다.

## 확인할 것

시범 독자에게 `어떤 부분이 내 이야기 같았는지`, `어떤 해석이 뜬금없었는지`, `다음 장을 읽고 싶은 이유가 있는지`를 묻는다. 분석 도구가 준비되면 무료 장면 완독률, 상세 안내 도달률, 결제 화면 진입률을 함께 본다. 결과가 좋지 않다면 그림 수를 늘리기 전에 장면과 해설의 연결을 수정한다.
