# 조사 메모와 출시 전 확인 사항

기준일: 2026-09-25. 경쟁 서비스는 **사용자 경험을 관찰하는 참고 자료**다. 캐릭터, 문구, 화면 구성, 광고 장면을 복제하지 않는다.

## 타이트사주에서 관찰한 점

- [공식 사이트](https://www.sajutight.me/)에는 범산도령, 연애, 궁합 등 여러 테마의 상품 배너가 있다. 캐릭터와 고민 주제를 함께 내세운다.
- [타이트사주의 MBTI×일간 목록](https://www.sajutight.me/mbti-ilgan)에는 16개 MBTI와 10개 일간의 조합이 이미 제시되어 있다. 따라서 두 분류를 단순 조합하는 것만으로 우리 서비스의 고유한 경험이 되기는 어렵다.
- [운영사 소개](https://groupby.kr/startups/1429)는 이용자 인터뷰에서 사주·타로를 통한 위로 수요를 발견했고, 웹툰·캐릭터 대화로 읽을거리를 만들었다고 설명한다. 초기 광고비 0원, 월 매출 등의 수치는 **운영사 발표**이며 독립 검증 자료로 취급하지 않는다.
- [대표 인터뷰](https://www.mt.co.kr/future/2026/08/16/2026080417541357071)는 다양한 테마와 재구매 사례를 설명한다. 우리에게 유용한 가설은 `구체적인 고민 → 캐릭터가 안내하는 이야기 → 다른 주제로 재방문`의 흐름이다. 각 요소가 매출에 얼마나 기여했는지는 공개 자료만으로 알 수 없다.
- 사용자의 관찰: 웹툰을 읽으며 스스로 이야기 안에 들어간 듯한 몰입감이 핵심으로 보인다. 이는 **우리의 해석**이며 성과 원인으로 검증된 사실은 아니다. [웹툰형 경험 스토리보드](EXPERIENCE_STORYBOARD.md)에서 독자적인 방식으로 시험한다.

## 우리에게 적용할 원칙

- 첫 광고의 질문, 랜딩의 약속, 무료 미리보기, 유료 결과의 내용이 한 주제로 이어지게 만든다.
- 캐릭터 A/B는 독자적인 외형·말투·세계관으로 발전시킨다. 참고 서비스와 혼동될 정도의 닮은꼴은 피한다.
- 상품 수는 초기 이용자의 읽기 완료·구매·재구매 반응을 본 뒤 늘린다. 현재 사이트의 큰 상품 목록을 초기 목표로 삼지 않는다.

## 주제별 수요: 연애·일·재물·건강 (2026-09-25 확인)

**결론은 조사 대상에 따라 다르다.** 젊은 층의 *구체적인 고민으로 점을 본 이유*에서는 연애가 일보다 앞서지만, 전체 성인의 *신년 운세 관심사*에서는 재물과 건강이 크다. 두 조사의 질문과 표본이 달라 숫자를 하나의 시장 순위로 합치지 않는다.

**제품 가설:** 첫 인스타그램 광고와 유료 테마는 `연애/관계`를 우선 검증한다. 두 번째 유료 후보는 기존의 `자기이해`와 `진로/일`을 비교한다. `재물`은 신년 시즌과 더 넓은 연령 확장의 후보로 두되 초기부터 제외하지 않는다. `건강`은 관심도와 실제 구매 의도가 다를 수 있으므로 후순위로 검증한다. 무료 결과의 자기이해 요소는 공통 경험으로 유지한다.

**검증 방법:** 같은 캐릭터·가격·랜딩 구조를 유지한 채 `연애`, `일`, `재물` 광고 문구를 작은 예산으로 비교하고, 클릭률뿐 아니라 무료 결과 완독률·결제 화면 진입률·구매당 광고비를 본다. 첫 화면의 테마 선택률과 구매 후 다른 주제 선택률도 기록한다. 공개 자료만으로 우리 고객의 결제 순위를 확정하지 않는다.

## 지식재산권 확인

- [한국저작권위원회](https://www.copyright.or.kr/information-materials/common-sense/knowledge-for-netizen/index.do)는 아이디어와 창작적 표현을 구분한다. 이미지·영상·카피·구체적인 캐릭터 표현은 독자 제작하고 사용 권리를 기록한다.
- [지식재산처의 BM특허 안내](https://kipo.go.kr/ko/kpoContentView.do?menuCd=SCD0200230)에 따르면 기술로 구현된 영업방법도 등록 특허가 될 수 있다. 출시 전 핵심 구현과 관련된 권리의 청구항을 확인한다.
- [KIPRIS](https://www.kipris.or.kr/khome/main.do)에서 브랜드 후보의 유사 상표, 관련 특허·디자인을 확인한다. 이름 한 번 검색한 결과를 권리 침해 여부에 대한 최종 결론으로 쓰지 않는다.
- 전체 화면·브랜드 인상의 혼동 가능성도 검토한다. [부정경쟁방지법](https://www.law.go.kr/LSW/lsInfoP.do?ancYnChk=0&chrClsCd=010202&efYd=20260528&lsiSeq=271245&urlMode=lsEfInfoR&viewCls=lsRvsDocInfoR)을 참고하되 구체적 판단이 필요한 경우 전문가에게 검토받는다.

## 운영·사업 준비에서 확인할 것

- 광주청년일경험드림 참여 중 사업자등록과 유료 영업 가능 여부는 사업단의 실제 조건으로 확인한다. 종료 예정일은 사용자가 말한 2026-10-31이다.
- PG의 업종 심사, 환불·취소 기능, 이용약관·개인정보 처리방침, 사용자 출생정보의 저장·삭제 범위를 정한다.
- 인스타그램 광고를 집행할 때는 클릭 이후 결제까지의 실제 전환과 광고비를 함께 본다. 경쟁사의 발표 수치를 우리의 예상 매출로 사용하지 않는다.
