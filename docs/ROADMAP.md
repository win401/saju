## V1 집중 순서

1. **정통 사주 우선 완성:** 기본 사주의 기질·오행·십성·일과 재물·대인관계를 밀도 있게 읽도록 검수한다. 메인은 정통 사주·연애 사주·사주×MBTI의 세 상품을 고르는 구조로 전환했다.
2. **캐릭터와 첫 장면:** 여울의 첫 화면, 관심 장면 선택과 상세 장 넘기기를 구현했다. 시범 독자에게 장면과 해설의 연결을 확인한다.
3. **시각 완성:** 여울의 후속 표정·상황 컷과 광고용 짧은 영상을 제작하고, 모바일 로딩과 접근성을 정리한다.
4. **운영 완성:** 실제 결제·재열람·개인정보 삭제·운영 분석까지 연결한다. 더 넓은 연령대와 다른 테마는 V1 사용 결과로 우선순위를 정한다.
