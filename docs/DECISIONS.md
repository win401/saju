# 결정 기록

`확정`은 현재 개발 기준, `제안`은 검증할 방향, `미결정`은 선택을 남겨둔 항목이다. 변경 시 기존 행을 지우기보다 날짜·이유를 추가한다.

| 날짜 | 상태 | 항목 | 내용과 이유 |
| --- | --- | --- | --- |
| 2026-09-25 | 확정 | 출시 순서 | 한국어·한국 출생 기준으로 먼저 개발하고 해외판은 이후 검토한다. |
| 2026-09-25 | 확정 | 화면 | 인스타그램 유입을 고려해 모바일 화면을 우선한다. PC에서는 모바일 폭으로 표시한다. |
| 2026-09-25 | 확정 | 스타일 | 사용자가 직접 수정하기 쉬운 일반 CSS를 쓴다. |
| 2026-09-25 | 확정 | 성별 입력 | 사용자 성별을 선택받고 `여성/남성/다른 성별/밝히지 않음`을 제공한다. 현재 원국·해설 계산에는 반영하지 않는다. |
| 2026-09-25 | 확정 | MBTI | 자체 검사를 제공하지 않고 사용자가 아는 유형을 선택적으로 입력한다. 미입력 시 추정하지 않는다. |
| 2026-09-25 | 확정 | 개발 중 결제 | 0원 모의 주문만 허용한다. 운영 환경에서는 모의 주문을 차단한다. |
| 2026-09-25 | 확정 | 실험 브랜치 | `main`을 공통 기준으로 두고 웹툰 장면형과 상황 카드형을 각각 `prototype/webtoon`, `prototype/interactive`에서 비교한다. 채택할 경험은 미결정이다. |
| 2026-09-25 | 제안 | 첫 상품군 | 공통 무료 미리보기와 유료 관계/연애·자기이해 2개 테마를 우선 검토한다. 현재 구현된 유료 테마는 관계 1개다. |
| 2026-09-25 | 제안 | 웹툰형 경험 | 사용자가 자기 이야기를 장면으로 따라가게 하는 세로형 리포트를 시제품으로 검증한다. 삽화와 말풍선만 추가하는 것으로 완료하지 않는다. |
| 2026-09-25 | 제안 | 참여형 경험 | 사주 해석·사용자가 선택한 MBTI·실제 상황에서의 자기 선택을 세 시선으로 비교하는 상황 카드를 시제품으로 검증한다. MBTI 재검사나 정확도 점수는 만들지 않는다. |
| 2026-09-25 | 제안 | 그림 제작·개인화 | 첫 출시의 컷은 미리 제작하고 사용자 입력에 따라 장면·대사·해설을 조합한다. 사용자별 실시간 이미지 생성은 유료 특별 컷의 수요가 확인된 뒤 검토한다. |
| 2026-09-25 | 제안 | AI 활용 | 사주 계산은 코드로 고정하고, 검수된 입력을 바탕으로 서버 측 일반 모델 API를 유료 문안 생성에 사용하는 방향을 검토한다. 별도 모델 학습은 초기 범위가 아니다. |
| 2026-09-25 | 미결정 | 캐릭터 | A·B 시안을 비교 중이다. 캐릭터명·외형·영상 스타일을 아직 확정하지 않았다. |

| 2026-09-25 | 미결정 | 세 번째 테마 | 진로·일, 궁합 중 수요와 제작 난도를 보고 결정한다. |
| 2026-09-25 | 후속 | 관상 | 사진 처리와 별도 동의가 필요한 확장 기능으로 둔다. 추가 요금 여부도 미정이다. |

## 판단이 필요한 질문

1. 무료 미리보기가 실제로 사용자의 호기심과 신뢰를 함께 만드는가?
2. 관계 리포트에서 사용자가 결제할 만한 고유한 내용은 무엇인가?
3. A/B 캐릭터 중 어느 쪽이 광고와 리포트 모두에서 더 잘 작동하는가?
4. 유료 콘텐츠를 규칙 기반으로 유지할지, AI를 어디까지 사용할지?
5. 일경험드림 참여 조건과 사업자·결제 개시 시점은 무엇인가?
