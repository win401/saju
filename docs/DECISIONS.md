## 판단이 필요한 질문

1. 무료 미리보기가 실제로 사용자의 호기심과 신뢰를 함께 만드는가?
2. 관계 리포트에서 사용자가 결제할 만한 고유한 내용은 무엇인가?
3. 여울의 서재 장면과 세 갈래 선택이 실제로 입력 완료·무료 결과 완독을 돕는가?
4. 유료 콘텐츠를 규칙 기반으로 유지할지, AI를 어디까지 사용할지?
5. 일경험드림 참여 조건과 사업자·결제 개시 시점은 무엇인가?

## 2026-09-26 — 정통 사주를 중심으로 메인과 세 상품 분리

관계 질문 위주의 기존 첫 콘텐츠가 흥미롭지 않다는 사용자 피드백을 반영했다. 메인은 정통 사주·연애 사주·사주×MBTI로 구성하고 정통 사주를 우선 완성한다. 각 상품의 실제 입력·무료 설명·상세 본문을 분리한다. 상세 내용은 [구조 문서](CONTENT_ARCHITECTURE.md)에 기록한다.
