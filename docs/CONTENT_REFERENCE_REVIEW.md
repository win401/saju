# 사주 원고 레퍼런스 조사와 개편 제안

조사일: 2026-09-26, 청월당 실제 상품 추가 확인: 2026-09-27. 상태: **조사 완료 / 원고 개편 제안**. 이번 작업에서는 서비스 코드·AI 프롬프트·배포를 변경하지 않았다.

사용자 피드백: 어려운 단어가 많고, 읽은 뒤 얻는 내용이 부족하다. 기본 리포트와 선택형 AI 상담을 모두 조사 범위로 삼았다. 사용자가 이번에 생성한 실제 AI 답변 원문은 제공되지 않았으므로 그 답변을 직접 평가한 것은 아니다.

- `web/src/features/relationship/server/report.ts:348–404`: 가까워지는 속도·표현·갈등·관계 유지에 내용이 집중된다. 끌리는 상대, 편안한 상대, 반복되는 연애의 시작과 끝 등 질문별 차이를 더 선명하게 만들 수 있다.
- `web/src/features/mbti/server/report.ts:109–113,199–213`: 두 사주 단서를 네 장에 반복 적용하고 MBTI 축별 설명과 연결한다. 같은 사건에서 두 관점이 어떻게 함께 작동하는지 보여주는 통합 문안이 부족하다.

### AI 연결 범위를 분명히 구분한다

정통·연애·MBTI 기본 리포트는 여전히 작성된 문안의 조합이다. OpenAI를 사용하는 것은 별도의 연애 상담이며, 현재 프롬프트 목표는 한국어 1,500~2,500자·3~5개 섹션이다. AI를 연결한 사실만으로 기본 리포트의 문체나 해석이 바뀌지는 않는다.

AI에는 확인된 원국 분류와 관계 해석 단서를 전달한다. 대운·세운·월운 등 시기 계산은 아직 제공하지 않는다. 경쟁 서비스처럼 시기까지 읽는 기능을 추가하려면 계산과 검증을 별도 작업으로 진행해야 한다. 문장을 풍부하게 만드는 작업과 시기 분석 기능은 구분한다.

## 3. 개편 원칙 제안

1. **첫 문장에 답을 둔다.** 독자가 원리를 다 읽은 후에야 결론을 만나는 구성을 바꾼다.
2. **본문은 생활어로 쓴다.** 한 장의 필수 전문용어는 0~1개를 목표로 하고 처음 나올 때 즉시 풀어준다. 상세 계산과 분류표는 기존 근거 펼침으로 보낸다.
3. **한 장마다 다른 발견을 준다.** 같은 장점을 다른 표현으로 반복하지 않는다. 중심 성향, 다른 단서와 만났을 때 생기는 차이, 생활 장면, 잘 풀릴 조건, 어려워질 조건, 해볼 선택으로 내용을 발전시킨다.
4. **개인화의 이유를 남긴다.** 쉬운 문장도 실제 계산 단서와 연결한다. 모든 사람에게 붙일 수 있는 관계 조언만으로 채우지 않는다.
5. **장면을 지어낸 과거로 말하지 않는다.** 입력받은 경험은 사실로 연결하고, 입력받지 않은 경험은 예시나 확인 질문으로 표현한다.
6. **공통 한계 안내를 반복하지 않는다.** 결과 시작의 짧은 안내와 펼침 근거를 활용한다. 출생시간 미상 등 특정 결론을 바꾸는 한계는 해당 장에 한 번 설명한다.
7. **캐릭터의 역할은 해석을 연결하는 것이다.** 애칭·감탄사·반말을 늘리는 것으로 말투를 만들지 않는다. 여울은 따뜻한 존댓말을 유지하되 결론과 장면은 구체적으로 말한다.

## 4. 정통 사주 목차 개편안

기존의 일간→오행→십성 순서는 계산 근거를 보는 화면에 남기고, 읽는 본문의 순서는 다음처럼 제안한다. 제목은 최종 확정 전 사용자 검토용이다.

| 장 | 독자가 얻을 답 | 내용의 차별점 |
| --- | --- | --- |
| 내 사주에서 먼저 보이는 세 가지 | 어떤 특징을 중심으로 읽으면 되는가 | 서로 다른 핵심 3개와 각 근거를 짧게 연결 |
| 남들이 보는 나와 실제 내 마음 | 겉으로 드러나는 방식과 속의 기준은 어떻게 다른가 | 두 단서를 같은 생활 장면에 함께 적용 |
| 잘하는 일과 유독 지치는 일 | 어떤 과제·환경에서 장점이 드러나는가 | 직업명을 단정하는 대신 업무 장면과 일하는 조건 비교 |
| 돈을 벌고 쓸 때 중요하게 보는 것 | 자원을 확보·관리·사용하는 관점을 어떻게 읽는가 | 소비 경험을 확정하지 않고 다른 선택지를 구체적으로 비교 |
| 끌리는 사람과 편안한 사람 | 호감의 기준과 관계를 유지하는 기준은 무엇인가 | 첫인상과 실제 관계의 장면을 분리 |
| 관계에서 반복해서 부딪히는 지점 | 좋은 의도가 어떤 오해로 이어질 수 있는가 | 내 의도→상대에게 보일 모습→조정할 행동 |
| 일이 꼬일 때 돌아볼 선택 | 강점이 부담으로 바뀌는 조건은 무엇인가 | 같은 충고 반복 대신 상황별 분기 |
| 나에게 남기는 세 가지 기준 | 앞의 내용을 생활에서 어떻게 사용하면 되는가 | 이전 장의 핵심을 요약하고 선택 기준으로 마무리 |

무료 미리보기에는 용어 소개만 두지 않고 **완결된 개인 해석 한 장과 서로 다른 핵심 세 가지**를 제공하는 안을 우선 검토한다. 상세 장은 다른 질문에 답하며, 무료 내용을 바꿔 말하는 방식으로 늘리지 않는다.

## 5. 직접 작성한 문체 예시

다음은 실제 사용자 분석이나 검증된 성격 판단이 아니라, 편집 방식의 차이를 보여주기 위한 가상 예시다. 최종 결과에 사용할 때는 해당 원국과 입력 상황에 맞는 근거가 필요하다.

### 추상적인 설명을 장면으로 바꾸기

현재 문장:

> 관리할 항목과 숫자로 담기 어려운 만족을 서로 다른 층위로 보는 균형이 있습니다.

개작 방향:

> 돈을 아껴야 마음이 놓이는데, 좋아하는 일까지 모두 미루고 싶지는 않을 수 있어요. 예를 들어 가계부를 꼼꼼하게 써놓고도 여행 한 번에는 기꺼이 돈을 쓰는 모습이죠. 이럴 때는 지출을 전부 줄이는 계획보다, 꼭 남길 돈과 마음 편히 쓸 돈을 따로 정해두는 기준이 도움이 될 수 있어요. 아꼈는데도 계속 서운하다면, 금액뿐 아니라 무엇을 위해 아끼고 있는지도 돌아보세요.

### 단순한 연애 조언을 읽을 내용으로 발전시키기

가상 고민: 연락은 이어지지만 상대가 만날 약속을 잡지 않아 헷갈리는 상황.

> 지금 확인할 것은 답장의 속도보다, 대화가 실제 만남으로 이어지는지예요. 매일 안부를 나누더라도 약속 얘기만 나오면 흐려진다면 마음을 더 쏟기 전에 확인할 것이 남아 있어요.
>
> 예를 들어 “언제 한번 보자”가 반복되는 상황이라면 이번에는 “나는 토요일 오후가 괜찮은데, 너는 어때?”처럼 한 번 구체적으로 제안해보세요. 그날이 어렵다는 답을 받더라도 상대가 다른 날짜를 제안하는지 볼 수 있죠. 말투가 다정한지보다 서로 시간을 내려고 하는지가 지금 고민에는 더 도움이 되는 단서예요.
>
> 한 번 약속이 어긋난 것만으로 마음이 없다고 결론 낼 필요는 없어요. 다만 구체적인 제안이 계속 미뤄지고 대안도 없다면, 관계를 앞으로 움직이는 일을 나만 맡고 있는지 돌아볼 때예요.

이 예시의 행동 조언 자체는 사주 근거가 아니다. 실제 상담 원고에서는 **계산된 두 단서를 쉬운 말로 연결한 개인 해석**을 별도 문단에 넣고, 사용자 고민과 만나는 지점을 설명해야 한다. 일반 관계 조언만 늘리는 것은 현재 문제를 해결하지 못한다.

## 6. 다음 구현의 우선순위와 검수 기준

제안 순서:

1. 정통 사주 무료 첫 장과 상세 한 장을 같은 가상 입력으로 먼저 전면 개작한다.
2. 기존 원고·개작 원고를 실제 독자가 나란히 읽고 쉬움·새로운 발견·반복 여부를 비교한다.
3. 한 장의 편집 기준이 잡히면 정통 전체에 적용하고, 연애·MBTI도 같은 질문을 반복하지 않도록 분리한다.
4. AI 상담은 질문과 상태에 맞는 답, 근거 두 개의 연결, 실제 장면을 우선 검수한다. 필요할 때 완결된 심화 내용을 늘리고 짧은 후속 질문에는 불필요한 장문을 강제하지 않는다.
