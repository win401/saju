# 결 — 캐릭터와 함께 읽는 사주 리포트

출생정보를 바탕으로 **정통 사주 · 연애 사주 · 사주×MBTI**를 읽는 모바일 중심 웹 프로젝트입니다. 서버에서 계산한 사주 정보와 규칙 기반 해석을 연결하고, 캐릭터 ‘여울’과 장별 리더로 결과를 보여줍니다.

[공개 데모](https://gyeol-saju-two.vercel.app/) · [개발 안내](web/README.md) · [구현·검증·배포 기록](docs/DEPLOYMENT.md)

포트폴리오 데모로 운영하며 실제 결제는 없습니다. 최신 변경의 배포 여부와 검증 범위는 배포 기록에서 구분합니다.

## 빠르게 둘러보기

1. 메인에서 정통 사주, 연애 사주, 사주×MBTI 중 하나를 선택합니다.
2. 입력 화면의 샘플 체험으로 가상 프로필의 결과를 읽거나, 직접 출생정보를 입력합니다.
3. 무료 요약과 계산 근거를 확인하고 전체 리포트의 네 장을 넘겨봅니다. 공개 데모에서는 결제 과정 없이 열립니다.
4. 다른 콘텐츠로 이동해 같은 출생정보를 다른 관점으로 읽어봅니다.

샘플 체험은 개인정보 입력이나 API 키가 필요하지 않으며, 가상 프로필을 브라우저에 저장하지 않습니다. 연애 상담의 사전 작성 예시는 실시간 AI 답변과 구분해 표시합니다.

## 구현한 기능

- **세 가지 리포트:** 공용 입력·리더와 주제별 해석 모듈을 분리했습니다. MBTI는 사용자가 알고 있는 유형을 직접 선택합니다.
- **계산과 해석 분리:** 한국 음력 변환, 절기 기준 사주 네 기둥, 오행·십성·지장간 등의 계산 결과를 해석 규칙에 전달합니다. 각 장에서 사용한 근거를 펼쳐볼 수 있습니다.
- **모바일 읽기 경험:** 일반 CSS, 캐릭터 이미지 레이어 모션, 움직임 정지, 장별 탐색, 입력 수정과 오류 복구를 제공합니다.
- **프로필 재사용:** 선택한 기본 정보를 같은 브라우저에서 24시간 재사용하며, 저장 해제·삭제·만료를 처리합니다. 샘플 체험은 저장에서 제외합니다.
- **저장 없는 공개 리포트 API:** 요청마다 입력을 검증·계산하며 공개 데모의 출생정보와 리포트를 앱 DB·서버 Map·쿠키에 보관하지 않습니다.
- **선택형 AI 상담:** OpenAI 서버 연동, 전송 동의, 구조화 응답 검증, 접근 코드와 요청 제한을 구현했습니다. 기본 리포트와 사전 작성 예시는 외부 AI를 호출하지 않습니다.

## 기술과 데이터 흐름

| 영역 | 기술 |
| --- | --- |
| 웹·API | Next.js App Router, React, TypeScript |
| 화면 | 일반 CSS, Next Image, 분리된 캐릭터·배경 레이어 |
| 입력 검증 | Zod, 서버 동출처·요청 크기 검사 |
| 사주 계산 | `korean-lunar-calendar`, `lunar-typescript`, 자체 계산 정책·해석 규칙 |
| 선택형 상담 | OpenAI Responses API, 서버 측 구조화 출력 검증 |
| 검증·배포 | Vitest, Playwright, Vercel |

```text
출생정보 / 가상 샘플
  → 서버 입력 검증
  → 음력 변환·절기·사주 계산
  → 주제별 해석 규칙 선택
  → 무료 요약 / 전체 리포트 / 해석 근거 표시

선택형 상담: 사용자 질문·전송 동의·접근 코드
  → 서버에서 사주 근거 재계산 → OpenAI → 응답 검증 → 상담 화면
```

## 로컬 실행

Node.js 22 이상과 npm을 사용합니다. 저장소 루트에서 실행합니다.

```sh
npm --prefix web ci
npm --prefix web run dev:demo
```

[http://127.0.0.1:4173](http://127.0.0.1:4173)에서 공개 데모와 같은 무료 리포트 흐름을 확인합니다. 기본 기능에는 DB·PG·OpenAI 키가 필요하지 않습니다. 환경 변수와 선택형 AI 설정은 [web/.env.example](web/.env.example), [배포 안내](docs/DEPLOYMENT.md)를 참고하세요.

```sh
npm --prefix web run typecheck
npm --prefix web test
npm --prefix web run test:e2e
SAJU_PUBLIC_DEMO=1 npm --prefix web run build
```

브라우저 테스트는 설치된 Google Chrome을 사용합니다. 모드별 테스트 실행 조건은 [개발 안내](web/README.md)에 정리했습니다. 테스트 구성과 실제 실행 결과는 구분하며, 최신 통과 결과는 작업 기록을 기준으로 합니다.

## 범위와 한계

현재 계산은 양력 1990년 이후 한국 출생·고정 KST·자정 일주 변경 기준입니다. 출생시간을 모르면 시주를 제외합니다. 기본 해설은 규칙 기반이며, 사주·MBTI는 자기이해를 위한 참고 콘텐츠입니다.

실제 PG 결제, 로그인·영속 DB·구매 내역, 해외 시간대·진태양시·대운, MBTI 검사는 구현하지 않았습니다. AI 연동 구현과 실제 API 답변 품질 검증은 별개이며, 사전 작성 예시를 실시간 생성 결과로 소개하지 않습니다. 매출·이용자 성과·상용 계산 정확도를 검증한 프로젝트는 아닙니다.
